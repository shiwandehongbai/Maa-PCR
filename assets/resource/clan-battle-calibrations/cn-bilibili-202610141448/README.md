# 公会战模拟校准资源候选

适用内容版本：202610141448。候选范围为第 2 阶段（B）、全自有队伍和模拟战。自动选择支援、秒数轴、正式战和补偿未由本资源开放。

出战星级使用作业绑定、采集时间在 24 小时内的已确认账号资料 `battle_rarity`；不将解锁星级代替出战星级。画面继续核对实际五人、支援标记、目标和模拟模式。游戏中调整星级后，须重新同步账号资料并保存作业。该读取方式避免编队卡片星级与徽标动画交替造成识别失败。

样本均由真实游戏截图归一化生成，昵称、排名及非必要账号数值已遮蔽。识别区域保留原始像素；账号资料页未打包。来源和脱敏校验记录留在本地任务证据中。

本开发工作树可登记 simulation，用于已授权的生产 Owner 模拟验收。登记不代表 Owner 已通过，也不代表发布或安装。最终交付的可用范围由验收结果决定；Owner 验收失败时撤回登记或保持禁用。
