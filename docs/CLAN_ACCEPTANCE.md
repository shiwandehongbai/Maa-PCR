## 开场与继承设置

当前无轴开场校准要求从默认 1 倍速进入。程序自动核对账号，读取并记录原继承选项，临时关闭后再编队。确认伤害并记账后，恢复原选项，再返回所选模拟目标。原先已关闭时不多点一次。停止或页面不明后不继续输入，未恢复记录保留至同账号下一次明确 Start；战斗未决仍先停止。

恢复入口覆盖主菜单、冒险、团队战大厅、Boss 详情、保留的设定页及可确认的模拟编队页。模拟模式不明或处于其他页面时，先人工返回大厅，再明确开始；程序不在未知页面寻找按钮。新增设定页及模拟编队取消分支通过保存帧和离线导航检查，完整自动恢复的实机证据来自正常结算路径。

开场暂停只接受 1:30 或 1:29，并须同帧确认零伤害、五人 TP 为零、五个角色、目标和模拟模式。时钟使用两份真实模板，必须只有一个候选命中。SET、AUTO 和倍速逐次读回，恢复战斗后再核对一次；含战中切换的秒数轴仍使用原来的严格起始秒数与 1 倍速限制。

## 资料与结果保护

账号资料沿用既有 24 小时有效期，不伪造采集时间。解锁星级 `rarity` 不能代替出战星级 `battle_rarity`。游戏手动改星后须重新同步，再核对保存。协议同步可能使旧客户端断线，应先重新进入游戏。

已知伤害先写 Journal，再返回。返回失败保留伤害并停止；未决结果不重新开战。只有完整证据证明开战输入没有发送，才记录未出刀。

正式批次继续使用三刀槽位；已结算不重复，未知不重发。Boss 实例绑定实际期次、阶段、轮次和刷新证据。补偿以游戏实际发放及绑定队伍为准，目标未重新出现时保留，短补偿不自动截断完整秒数轴。

正式页面另取实际只读样本：大厅为 0／900 CP、0 次普通挑战和 0 次延长挑战；存活第三 Boss 为 50,000,000／50,000,000，已败第五 Boss 为 0／60,000,000。次数不足时，游戏在进入正式编队前提示累计 300 CP，已取消提示。只读原生回放确认大厅计数、存活目标完整字段和已败目标生命值；已败目标的次数字样置信度不足，完整观察保持失败，未降低阈值。模拟页和前往主线弹窗均不能作为正式观察。上述局部样本不构成正式执行校准，未采集正式消费或补偿发放／消费证据。

## 秒数轴实测

另一次模拟专门用于耗时校准，不计作纯 AUTO 作业验收。完整观察实测为 1,978.203 ms，超过 250 ms 门限。首次 AUTO 切换收到原生输入回执，但后态未确认；该失败尝试共 4,380.402 ms，不能算作成功切换样本。

有效完整观察只有 1 组，成功切换为 0 组，未达到每类至少 20 组。实验停止后没有补点或重试。同一场最终 60,000,000 伤害另经保存帧核验并记账，再返回大厅；这不改变切换失败结论。

识别、Owner 调度、PNG 记录及实验日志分别留有耗时。嵌套测量不能相加；Owner 调度包含 IPC，未单独拆分纯 IPC 耗时。实验窗口的截图子进程为 185～352 ms，包含 GUI 预览，不能逐条归因到某次完整观察。250／500 ms 门限未放宽，随包不登记 `timed`。
