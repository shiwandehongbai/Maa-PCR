## 执行约束

同一有效 Owner／设备连接实际核对一次玩家 ID，后续槽位复用绑定。切号、重连、来源或上下文失效后重新核对，不增加每刀简介、个人记录或继承页检查。

保留游戏的 SET、AUTO 和战斗速度继承。进战后读取实际状态，已匹配时直接使用；需要调整时先暂停，按角色 ID 只改差异，并逐项读回五人、开关和冻结的暂停秒数。正式普通挑战固定 2 倍速。

普通 90 秒挑战和模拟的开场调整须在受影响角色首次 UB 前完成。标准 90 秒普通挑战和模拟在 1:24 之前不会首次 UB；同一有效 Owner 的首次暂停读到 85～90 秒时，可按已确认规则核验。1:24 及之后、短补偿不套用该规则。普通攻击伤害和 TP 增长不作为统一停止条件，也不采用统一两秒期限。

模拟和正式保留各自的旧继承 Journal。旧待恢复项只在原账号明确 Start 后核对：真实现值已等于原值才凭读回结账；冲突时保留记录并停止。原战斗未决先阻断，不为恢复设置重开战斗。

正式批次沿用三刀槽位及 `observe → prepare → execute`。开战前核对实际五人、出战星级、支援、目标和消费模式。当日已用角色来自已结算 Journal；程序外人工出刀经事实确认后单列为外部消费；已有 intent 的人工恢复保留人工介入标记，不能计为自动验收。已结算不重复，未知开战或结果不重发。
