# Maa-PCR R50 使用说明

本版目标为 `v0.1.6 / R50`，合并日常拖动与识别优化、渠道预设、日志导出和遗物名称修复。正式发布状态及精确载荷验收见 Release 说明与 `delivery/acceptance.json`。黎明界继续标为测试版；局部离线测速不代表整体日常或真实整局提速已验证。

“高级设置 → 多显示屏映射校验”默认关闭。它用于核对截图所在物理屏幕与输入所在逻辑屏幕；单默认屏幕使用Maa默认截图/输入即可。游戏位于非默认显示屏时开启，无法确认映射会停止。设备、游戏前台、画面比例及停止保护始终保留，设置按配置保存。

目标为PCR国服、Windows 64位。保留日常及黎明界双配置，MuMu12和雷电9的实际兼容范围以实机证据为准。源码和运行包中的组件分别遵循其许可证与来源说明，不将整个项目视为统一MIT许可。

## 第一次打开

完整解压到自己能写入的文件夹，保留所有子目录；双击 `MFAAvalonia.exe` 或 `启动 Maa PCR.bat`。包内已有 Python、.NET 与 x64 Visual C++ 运行库，无需另装这些运行环境；不要单独复制 EXE 或删除同目录 DLL。

先在模拟器中手动登录 PCR 国服，使用 16:9 横屏并切回游戏主页。首批每个模拟器实例固定一个 PCR 账号，一次运行一个所选设备；换账号、多开并发和移机接续不在本轮支持范围。

在设备栏点击搜索，选择自己的设备，再点击连接。搜索不到时，可手动选择本机已有的 `adb.exe`，再填写目标地址。支持 `127.0.0.1:端口`、局域网 `IPv4:端口` 和 Maa 发现的 `emulator-N` 串号。连接通过 Maa 获取首帧，预览不会点击游戏。重开会恢复所选设备，但不会自动连接。

局域网地址支持 `10.*`、`172.16.*` 至 `172.31.*` 和 `192.168.*`，例如 `192.168.1.4:5555`。端口以你的模拟器设置为准，不能直接照抄示例。程序保留你选中的地址，不会替换为本机回环地址；开始前仍核验游戏前台和显示屏。公网地址、域名和 IPv6 暂不支持。

MuMu12 沿用已验证的入口。雷电9 和局域网 ADB 使用通用连接，日程绑定本次选中的设备。实际任务兼容仍需实机验证，连接成功不代表所选任务都能完成。

窗口最小尺寸为 700×500，较窄时可分别滚动模块列表和参数区域；底部开始／停止保持可见。

任务设置和勾选会自动保存，无设备也能先编辑。看到保存失败时先检查文件夹是否可写，修好后重新选择设备或保存设置。

### 渠道服配置

日常与扫荡共用任务流程，在“高级设置 → 渠道服配置”选择 B 服、小米、应用宝、九游、华为、vivo 或 MuMu，设置自动保存。玩家无需填写包名或 Activity。原 B 服配置自动对应 B 服预设，无需修改。

新增六种渠道的包名和游戏主 Activity 已按实际 11.7.2 APK 清单核对，启动页与游戏主界面分开记录。五种来自渠道官方分发入口，华为使用镜像样本并交叉核对相关项目记录，来源见 [渠道预设依据](CHANNEL_PRESETS.md)。OPPO 和 4399 尚缺完整成对证据，没有加入。未收录渠道请反馈维护者，不要选择其他渠道代替。

正常更新通常继续沿用已保存的渠道。若实际包名、运行 Activity 或界面变化，维护者按证据更新。旧手填配置只有与已收录预设完全对应时才可继续使用；不匹配的原配置仍保留，并提示选择预设，不自动套用 B 服。

开始前仍需玩家自行登录并回到游戏主页。程序核验所选设备、游戏前台和输入焦点，无法确认时停止，不自动登录或点击未知页面。切换渠道不能解除原未决记录，也不会迁移或改写旧账。此设置仅用于日常与扫荡，黎明界 bot 保持原有流程。

本次验证覆盖配置和离线模拟场景；各渠道的实际界面、当前活动及完整日常仍需现场验证，不代表所有渠道均已通过。

## 设置与开始

任务页顶部选择设备并连接；左侧“本次模块”勾选要执行的模块，点击模块名称后在右侧编辑该模块参数。点击模块名称只切换参数页，不改变是否执行。底部显示本次选集与运行状态，开始／停止按钮保持可见。无需再开启任务总开关，也无需选择 JSON、填写游戏日或重复声明。没有选择任何模块或末尾补领时会提示先选择任务。

| 模块 | 玩家需要准备的内容 |
|---|---|
| 日程 | 在游戏内设置原生一键计划；在 Maa 选择日程后点击开始 |
| 活动 | 在游戏内勾选活动困难关卡，目标为每关每日最多 3 次；兼容剧情活动 H-n 列表与旧复刻布局 |
| 深域、高难、困难 | 在游戏内保存关卡预选，再选择槽位与每关每日目标 |
| 普通 | 在游戏内保存关卡预选，再选择槽位与每关本次次数 |
| 深渊前哨 | 深渊讨伐战开放且已通关前哨；三项均有余次时按当前一键报价扫荡 Normal、Hard、Very Hard，最多每项 4 次；全部耗尽则跳过，部分耗尽的布局暂不支持；不打 Boss、不改变游戏选择 |
| 每日任务 | 领取当前可领取的每日任务与礼物；可选择末尾补领 |

深渊前哨会核对报价，再依次处理“挑战”和“扫荡券确认”两层页面，无需临时手动补点。报价或页面无法确认时会停止；请保留现场，不重复确认或重新扫荡。

扫荡槽位为 1–7，次数为 0–999；0 次表示本次跳过，槽位可留空。界面不会改变游戏内保存的关卡勾选。日程沿用游戏内计划，不重复配置子项；不购买、不重置、不使用宝石。

活动若自动出现“获得活动登录奖励”等弹窗，请先在游戏中查看并关闭回执，再回主页开始。程序遇到未识别弹窗会停止；不会代替玩家领取或关闭未知页面。当前剧情活动的最终确认与消费结算仍待实机验收。

在左侧同一份模块列表中勾选任务，并按住模块行左侧“≡”上下拖动调整先后。已勾选模块按列表从上到下执行，顺序自动保存，重开后保留；未勾选模块不执行。末尾补领始终在全部所选模块之后执行。运行时暂不可修改；正常结束或停止后可继续编辑。

开始前检查本次选集。执行结果分别报告已完成、条件不足跳过、失败与结果未确认；跳过并不代表目标已达成。所选模块安全结束，也不代表所有日常都已完成。

资源、控制器和旧配置导入等低频操作收纳在“高级设置”；运行日志可以展开查看。修改参数仍会自动保存，保存状态与运行结果分别显示。

黎明界登录需要人工完成官方极验验证码时，验证页默认显示在软件内的“人工安全验证”遮罩窗口中，完成后自动继续本次任务；可以点“取消本次验证”结束等待，也可以用“在浏览器中打开”改用系统浏览器。本机缺少 WebView2 运行时或内嵌窗口创建失败时，程序自动回退到系统浏览器打开同一页面。

黎明界协议登录和账号读取使用直连：程序不会把 Windows 系统代理交给这些游戏连接子进程，避免系统代理或代理节点抖动导致整批以网络错误结束。若本机必须通过代理才能访问国服，请在代理软件里让 bilibili 相关域名走直连，而不是让程序继承系统代理。在线更新检查与下载使用“更新设置”里的更新代理，可选“跟随系统”（默认）、“自定义代理”或“无代理”；本地校验、安装和恢复不联网。游戏内的数据库更新随游戏连接子进程直连，失败时继续使用已验证的本地数据。

## 停止、结果与反馈

运行时再次点击开始/停止按钮可请求停止。已发出的动作可能仍在结算，等界面回到空闲并查看结果。游戏画面未就绪时，在所选模拟器打开并登录 PCR，切回主页后再开始；程序不会自动重试。

若提示“结果未确认”或“未决记录”，保留现场和日志；不要删账、修改电脑日期、重装或新建目录来绕过。已确认结算但返回主页失败时，后续模块会停止，结算事实保留。

### 日程恢复

上次日程报错后，可正常点击开始重新观察。明确的地下城分层奖励页可以按专属按钮安全关闭；遇到新的消费确认会停止。若当前九项都已完成且回到主页，软件跳过日程并继续本次其他所选模块，旧任务仍保留为结果未知。

如果已经进入新一天：先在游戏中重新登录，确认今日任务已刷新；点击左侧“日程”后展开右侧“日程恢复”，勾选“我已重新登录并确认今天任务刷新（仅本次开始有效）”，再点击开始。程序会核对同一实例、游戏内日期与完整九项状态，随后只执行当天尚未完成的项目，并继续核对实际报价。确认每次开始后自动清除，不保存或复用。

恢复只会追加“历史结果未知”记录，旧根记录和动作账不改写，也不声称昨天成功。当天的新任务另记意图；如果它再次结果未知，当天仍不会重复消费。电脑日期变化、缺少游戏日期、状态读不全、换实例或同日确认都不能解锁。若刚关闭旧结果页而今日仍有未完成项，按提示重新开始核对。

任务停止后可点击“导出诊断”，或双击 `导出 Maa PCR 诊断.bat`。导出文件包含版本、manifest 标识、选集、运行编号和结果摘要；默认不包含设备信息、截图或账本，也不会自动发送。导出位置显示在界面，先查看摘要再自行提供给维护者。需要选择特定运行时，可用维护工具的 `--run-id` 参数；正常使用无需手改 JSON。

### 日志导出与自动清理

在黎明界配置中打开“导出日志”，默认包含黎明界运行日志、GUI 日志、Maa 日志和“失败现场截图”。不需要图片时可取消截图选项。日常配置沿用原有导出范围，黎明界记录位于 ZIP 内的 `.runtime/labyrinth-work/`。

黎明界的运行事件、恢复检查点和操作账本完整附带。原生日志默认选择全部，也可改为最近 24 小时、3 天或 7 天。时间筛选只影响导出的原生日志，不会删改本地记录。

失败现场截图使用每次失败时已保存的最多两张完整识别原帧，包含未识别页面，保存在 ZIP 内的 `.runtime/ocr-export/labyrinth/运行编号/`。截图时间范围由图片选项单独控制。每张图片附带对应运行编号、识别节点和文件摘要；账号密码配置、SDK 登录文件及原始识别参数不打包。图片和记录可能包含玩家 ID、设备标识和游戏信息，请按需分享。

如果原图已缺失、保存配额耗尽或文件校验失败，日志包会保留缺图说明，不会在导出时补拍。旧日志包里没有原图时无法补回；若本机还保留原图，更新软件后可重新导出，无需为取图重跑游戏。

导出窗口显示普通日志与黎明界独立记录的压缩前占用，不含截图。当前导出单个 ZIP，不自动拆分。

程序每次启动时检查并清理超过 30 天的普通旧日志，仅限 `logs/` 顶层的 GUI 滚动日志和 `debug/` 顶层的 Maa 备份日志。正在使用的文件和当前 Maa 日志保留；GUI 原有的 14 文件、每文件约 10 MiB 滚动上限继续生效，因此部分 GUI 日志可能更早轮换。清理收据保存在 `.runtime/log-maintenance/`。

黎明界账本、恢复检查点和独立原生日志，以及日常业务证据、截图、设置和未知结果记录，均不按日期自动删除。这些记录仍可能积累；需要释放这部分空间时，应先按运行记录的引用关系核对，不能直接删除 `.runtime`。

反馈请附 Windows 与模拟器版本、所选模块、操作步骤、界面完整提示及诊断摘要。日志与截图留在本地，按实际问题提供必要片段。

## 本地升级

取得同一发行布局的本地更新 ZIP 后，先正常退出 Maa PCR，再双击 `更新 Maa PCR.bat` 并选择更新包（也可将 ZIP 作为启动参数）。工具验证版本、manifest 和全部载荷后，只更新程序清单；设置、日志、账本、动作记录和引用证据保留。更新失败会恢复此前程序和 manifest，不自动启动任务。

更新过程中不要启动程序。若提示上次更新未完成，保留 `.runtime/player-maintenance` 中的记录和程序备份，按错误摘要核对或恢复程序；不要删除标记强行开始，也不要清账。更新事务只恢复程序，不改变游戏业务状态。

继续使用原安装目录。`导入旧配置`仅导入设置及兼容身份，不迁移账本；换目录或新装不能解除原未决记录。R39默认异步检查稳定版，玩家点击才下载安装，运行任务期间不能安装；升级后只重启GUI，不自动继续游戏。R38首次使用bootstrap补丁获得新入口，详见 [更新与恢复](UPDATES.md)。
