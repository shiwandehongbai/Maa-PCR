# 日志与问题反馈

## 查看实时日志

日常、黎明界和公会战都使用功能页面底部的实时日志栏。展开后可以看到本次运行的步骤、结果与停止原因。每行可以选中复制；向上滚动查看旧记录后，点击“到底部”恢复自动滚动。

面板显示最近 500 行。“清空”只清理面板，不删除文件，也不修改任务状态。

任务结束后，程序先释放执行资源，再允许切换功能。清理期间会显示进度。如果提示退出尚未确认，请保留记录并重启 Maa-PCR；不要通过清账或重放未知操作解决。

## 导出本次日志

点击“导出本次日志”，检查需要分享的截图，然后选择 ZIP 保存位置。日常、黎明界和公会战的记录分开保存，默认只导出当前功能最近一次运行。

每个功能的用户日志缓存合计最多 16 MiB，导出 ZIP 也不超过 16 MiB。程序保留近期文字、必要的底层运行片段和少量关键截图，空间不足时轮换旧诊断记录。没有可用截图时，日志会说明原因。登录、验证码及玩家资料页面不会自动附图。

这个限制不代表整个程序的磁盘占用。业务账本、未决记录、旧开发证据、原始调试资料和你已经另存的 ZIP 不参与这次轮换。

日志包采用固定文件清单，不打包账号凭据和原始业务账本。游戏截图仍可能含昵称或玩家 ID，请预览并取消不希望分享的图片。

## 反馈问题

报错后点击“反馈问题”。日志包准备好之后，可以选择：

- “准备 GitHub 反馈”：打开项目的预填 Issue 页面。登录 GitHub、补充复现步骤、附上 ZIP，然后提交。
- “准备邮件反馈”：打开邮件客户端，收件人为 a877236828@gmail.com。补充复现步骤，手动添加 ZIP 并发送。

浏览器或邮件客户端无法打开时，可以使用“复制反馈说明”“复制反馈邮箱”和“打开日志包位置”。你可以使用任意邮箱发送反馈，不需要 GitHub 账号。

“日志包已准备”表示文件已生成。软件不会自动上传日志、发送邮件或声称反馈已经提交。

## 启动设置

单功能的启动设置继续保留。选择带参数的 Windows 快捷方式时，程序会保留快捷方式的启动参数及工作目录。“附加命令”非空时优先使用你填写的命令，否则使用快捷方式参数。

当前 PCR 模式隐藏了无效的跨功能批量启动区域。你仍可以运行日常，等资源释放后手动切换到黎明界或公会战。
